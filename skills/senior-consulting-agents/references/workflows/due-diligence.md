# Prepare scoped transaction diligence findings

Read [shared standards](../deliverable-standards.md) and the linked engagement method once per context.

Prepare diligence for: the user's request
Lead: `financial-due-diligence`. Add `mergers-acquisitions-tax` for tax/structuring exposure, `strategy-director` for commercial questions and `technology-consulting-architect` for material technology dependencies. Load only needed specialists; explain an exception to the normal limit if all three are material.
Confirm transaction perimeter, decision stage, period and available evidence. Bridge reported to adjusted EBITDA with supported adjustment rationale; test recurrence/double counting; assess NWC seasonality, net debt and overlaps. Never invent missing financials.
Deliver red flags, adjustment schedule, NWC/net debt items, relevant tax/commercial/technology findings, proposed deal protections and prioritized information requests. Complete when material findings connect to a transaction decision, evidence and unresolved exposure; distinguish hypotheses from verified diligence results.
