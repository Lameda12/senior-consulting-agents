# Assess sustainability readiness and evidence gaps

Read [shared standards](../deliverable-standards.md) and the linked engagement method once per context.

Assess readiness for: the user's request
Lead: `esg-advisory`; use `esg-assurance` for reporting controls or assurance readiness.
Confirm entity scope, jurisdiction, reporting period and applicable regime using current authoritative sources before claiming an obligation. Cover relevant materiality, data/control gaps, Scope 1–3 boundaries and roadmap. Do not apply every listed regime universally or infer applicability from company size alone.
Deliver an evidence-linked gap assessment and owner-based roadmap. Complete when applicability is supported or explicitly unverified, material data limitations are visible and actions specify closure evidence. Readiness is not an assurance opinion.
