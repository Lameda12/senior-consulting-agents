# Prepare a supported valuation approach

Read [shared standards](../deliverable-standards.md) and the linked engagement method once per context.

Set out a valuation for: the user's request
Lead: `valuations`. Add `corporate-finance-modeling` for material model construction/validation.
Establish purpose, valuation date, basis of value, perimeter, units/currency and available financials. Cover relevant approaches (DCF, multiples, precedents), discount-rate assumptions, enterprise-to-equity bridge and sensitivities. Use current sourced inputs where required; missing market data remains a gap.
Deliver an editable approach/model outline; include sensitivity and football-field tables only where supported by inputs. Complete when calculations reconcile, methods use compatible bases and conclusions distinguish illustrative scenarios from supportable valuation estimates.
