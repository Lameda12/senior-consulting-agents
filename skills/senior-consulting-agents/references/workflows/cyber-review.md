# Assess cyber evidence and remediation priorities

Read [shared standards](../deliverable-standards.md) and the linked engagement method once per context.

Assess: the user's request
Lead: `cyber-security`. Add `privacy-data-protection` only for material privacy obligations.
Map evidence to NIST CSF 2.0 outcomes and functions. Confirm scope and evidence period. Use the client's defined assessment scale if supplied. Otherwise use evidenced / partial / gap / unknown with rationale; do not invent 0–5 maturity scores or equate them with NIST Implementation Tiers.
Prioritize supported risks, owners and a 90-day/12-month roadmap. Complete when each conclusion traces to evidence, unknowns remain visible and actions specify closure evidence. Include a concise board summary and distinguish desk assessment from tested effectiveness.
