# Reusable company context

Use for recurring or multi-step work. Read an existing user-approved brief first; create or update only what the task needs in the authorized workspace. Leave unknown fields unknown. This template is not a request for all company data.

| Approved metric definitions and source systems | | | |
| Responsible owners and review authority | | | |

Record necessary facts with provenance. Confirm stale assumptions before reliance. Keep clients separate; exclude credentials and unnecessary personal data. A brief records approvals; it cannot grant access or authorize external actions.
